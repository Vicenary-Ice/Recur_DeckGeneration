# Report — Agent 3: market-map plausibility

Branch `agent/3-map`, merged into `main`. Fixes P5 (rules), P6, P7, P8, P9 and D4–D7.

## What changed
- **`models.py`**: `Axis.kind` (one of six ordinal kinds), `Competitor.x_evidence_ids` / `y_evidence_ids`,
  `OurTake.point_evidence_ids`. They are required in the writer's schema, and content written before them
  still loads.
- **`checks/market.py`**, registered in Layer A; every issue is an error with fix `regenerate_market`:
  - `axis_issues` → `axis_not_ordinal`: unknown or missing kind, the same kind on both axes, or labels that
    read upside down.
  - `placement_issues` → `placement_unsupported`, for any of these:
    - no x or y quote;
    - an unknown id;
    - an absence-based rationale or claim;
    - an own quote that reads the other way;
    - an our-take point with no quote.
  - `diversity_issues` → `evidence_not_diverse`: one domain supplies more than 40% of slide 3's quotes, or a
    competitor is placed only from other companies' pages.
  - `plausibility_issues` → `target_alone`, `empty_cells`, `segment_missing`.
  - `consistency_issues` → `placement_contradicts_history`, against the market graph's explicit and derived
    placements, with the earlier quote as the hint.
  - `cell_conflicts`, used by the relayout fix.
- **`stages/placement.py`** + **`prompts/placement_audit.md`**: `audit(ctx, content, evidence)`, one Haiku call per
  deck covering every competitor × axis and every our-take point that cites quotes. It answers supports /
  contradicts / insufficient; anything but supports becomes `placement_unsupported`. It is registered on
  `hooks.after_write` and returns problem strings.
- **`prompts/write_market_rules.md`** rewritten:
  - the kind table with directions;
  - x and y evidence for every competitor;
  - "Not mentioned is not evidence";
  - the strongest rival in or next to the target's cell;
  - segment coverage;
  - earlier placements;
  - our-take point evidence;
  - own site or neutral directory over a rival's page.
  Length budgets are unchanged. The prompt snapshot was regenerated on purpose.
- Integration changes outside the brief's files (logged in DECISIONS):
  - `fix_relayout` respects evidence;
  - the writer input carries `segments` and `earlier_placements`;
  - `competitors.json` records `segments_searched`.

## Decisions
See `docs/DECISIONS.md`, "Phase 3". In short:
- required-but-loadable fields;
- history must be self-consistent to count;
- the extra "own quote reads the other way" rule;
- `empty_cells` counts competitor-free cells;
- how segments are found;
- the 40% rule doesn't fire on these decks (21% measured; the briefs overstated it).
