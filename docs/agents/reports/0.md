- **Git.** `git init` on `main`; `.gitignore` covers `.env`, `.venv/`, `runs/`, `output/`, `out/`, caches,
  `*.egg-info/`, `Recur_CaseProject_kit.zip` and `docs/Recur_agent_briefs.zip`. Commit

- **Check registry** `recur_deck/checks/__init__.py`: `@register`, `run_registered(content, manifest,
  logo_metrics, extra)`, auto-import of every submodule; a check that raises becomes a `check_failed` warning.
  `qa.run_all(..., extra=None)` appends the registered checks. `pipeline.QAState.check_extra()` passes
  `evidence, entity, graph, run_dir, profile, comps, logos`.
- **Hooks** `recur_deck/hooks.py`: `on(name)`, `fire(name, **kw)` (flattened results, failures logged and
  skipped), plugin modules imported on first fire. `pipeline.py` fires `after_profile`, `after_competitors`,
  `after_write`, `after_vision` (when the vision check passes) and `after_run` (after the report is written).
  Return values are only logged for now.
- **Market-graph stub** `recur_deck/market_graph.py`: `MarketGraph.neighbors/placements/add_run/save`,
  `load(settings)`, `from_runs(dirs)`; path `runs/_market_graph.json` or env `RECUR_MARKET_GRAPH`. The pipeline
  loads it into `QAState.graph`.
- **Prompt split**: `prompts/write_deck.md` is now the skeleton (`{THESIS_RULES}{MARKET_RULES}`,
  `{STYLE_RULES}`, `{STYLE_EXAMPLES}`); `write_thesis_rules.md`, `write_market_rules.md`,
  `style_examples/00_recur_ai2000.md`. `write.writer_system_prompt()` renders it; byte-identical to the
